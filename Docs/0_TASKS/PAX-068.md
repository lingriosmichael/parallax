# PAX-068 · Store listing and compliance (developer checklist)

**Status:** Draft. Mostly developer work in Play Console; the Architect can draft texts.
**Phase:** Solo v1, Phase G
**Depends on:** PAX-A10, PAX-067

## Checklist

1. **Account type:** personal account created after 13 Nov 2023 → the closed test (≥ 12 testers
   opted in for 14 continuous days) is required before production access (PAX-070). An
   organization account (D-U-N-S) is exempt. Decide/confirm now; recruiting takes time.
2. **App created** in Play Console; package name matches PAX-067.
3. **Listing:** title, short description, full description (English; others later), graphics
   from PAX-A10, category Puzzle or Action (decide), contact email.
4. **Privacy policy URL:** hosted page stating no personal data collected; local-only saves;
   purchases handled by Google Play.
5. **Data safety form:** no data collected/shared (confirm Unity IAP and Unity services config
   match; if Unity Analytics or any Unity Gaming Services are enabled by default, disable or
   declare).
6. **Content rating** questionnaire (IARC); cartoon peril at most.
7. **Target audience:** not directed at children (avoids Families policy); ads declaration: none.
8. **In-app product** `full_unlock` created, price per D-067, active.
9. **Internal testing track:** upload the PAX-067 AAB (needed for PAX-037's real-billing test).

## Output

A `Docs/Release/play_console_status.md` with each item ticked and dated.
