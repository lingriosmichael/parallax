# PAX-065 · Haptics

**Status:** Built 2026-10-31 on a batch clone; the developer's menus and a phone test are pending (§8, §9). The draft below is kept; §8 records what was built and where it differs.
**Phase:** Solo v1, Phase F
**Depends on:** PAX-064 (`TrapFired` event)
**Decisions:** Vision §9, D-062 (7), D-064

---

## 1. Why

Trap firings should be felt as well as heard (Vision §9); the settings toggle exists (PAX-054).

## 2. What to build

1. **`IHaptics`** (`Parallax.Core`) with `Play(HapticCue)`; cues: TrapFire (light), Death
   (medium), LevelComplete (success pattern), UiTap (very light, optional).
2. **`AndroidHaptics`** (`Parallax.Gameplay`, `#if UNITY_ANDROID && !UNITY_EDITOR`): Android
   `Vibrator`/`VibrationEffect` through `AndroidJavaObject`, amplitude when
   `hasAmplitudeControl()`, otherwise `Handheld.Vibrate()` for strong cues only. Referencing
   `Handheld.Vibrate` also makes Unity add the `VIBRATE` permission; confirm it in the PAX-067
   build's merged manifest.
3. **`EditorHaptics`**: logs the cue (so Editor acceptance can see them).
4. **`HapticsConfig`** asset: duration/amplitude per cue; a minimum gap between cues so chained
   traps don't buzz continuously.
5. Respects `HapticsEnabled`; off → no calls at all.

## 3. Rules

No packages, no custom manifest file, no ProjectSettings edits · haptics never affect gameplay.

## 4. Tests (EditMode)

Cue mapping per event; minimum gap; disabled → zero calls (fake `IHaptics`).

## 5. Allowed files

New files under `Core`, `Gameplay`, `Data`, `Tests/EditMode`; `GameAudio` or the composition root
for wiring.

## 6. YOU — UNITY EDITOR

Run All; play a level, see the log lines per cue; toggle off → none. Feel is **device-only,
unverified (Phase H)**.

## 7. Required output

As `CLAUDE.md`, review file `pax065_review.txt`. Commit: `PAX-065: haptics`.

## 8. As built (D-278, 2026-10-31)

The developer: "build it next", after being told the setting the draft relied on didn't exist.

**Differences from the draft:**
- **§1, the settings toggle:** PAX-054 stored none. `LevelProgressStore.HapticsEnabled` is new (on by default), and the pause panel has a new
  **Vibration: On/Off** button, because the game has no settings screen. So the allowed list grew by `PausePanel`, `PauseMenuSetup`,
  `LevelProgressStore` and `AudioSetup` (`Find` made internal).
- **§2.1, UiTap:** left out; it was optional. The cues are TrapFire, Death and LevelComplete.
- **§2.2:** API 25 has no `VibrationEffect`, so a phone below API 26, or one with no amplitude control, plays Death and LevelComplete with
  `Handheld.Vibrate()` and skips TrapFire, as the draft's "strong cues only".
- **Vision §9 ("every trap firing"):** a trap buzzes only within `trapWithin` (9 u) of the cat and `minGap` (0.25 s) after any cue, or a hall
  of gates would buzz nonstop. Deaths and level complete always play. Sound has the same distance rule.

**Files:**
- **Core:** `Core/Audio/Haptics.cs` (`HapticCue`, `IHaptics`, `HapticDispatcher`).
- **Gameplay:** `Gameplay/Audio/HapticsConfig.cs`, `LevelHaptics.cs`, `AndroidHaptics.cs`, `EditorHaptics.cs`; `Gameplay/Levels/LevelProgressStore.cs`;
  `Gameplay/UI/PausePanel.cs`.
- **Editor:** `Editor/Setup/HapticsSetup.cs` (the menu `PARALLAX/Setup/Haptics (PAX-065)`), `PauseMenuSetup.cs`, `AudioSetup.cs`.

- **Docs:** this ticket, `07_DECISIONS.md` D-278, `08_V1_ROADMAP.md`.

## 9. YOU — UNITY EDITOR (as built)

1. Save the open scene.
2. Run `PARALLAX/Setup/Audio (PAX-064)` if it hasn't run since PAX-125.
3. Run **`PARALLAX/Setup/Haptics (PAX-065)`**. It creates `Assets/_Game/Data/HapticsConfig.asset` and edits and saves `_LevelTemplate`.
4. Run **`PARALLAX/Setup/Levels/Rebuild All Levels`**.
5. **Editor:** play a level. The console logs `Haptics: TrapFire`, `Death` and `LevelComplete`. Pause, tap Vibration so it reads Off, resume: no more lines.
6. **Device:** build to a phone and check:
   - near traps tick lightly, and a hall of gates doesn't feel nonstop;
   - death is firmer than a trap, and level complete is a short pattern;
   - the setting survives closing the app;
   - the merged manifest has the `VIBRATE` permission (PAX-067's build).

Tune the feel in `HapticsConfig.asset`: each cue's lengths and strengths, `minGap`, `trapWithin`.
