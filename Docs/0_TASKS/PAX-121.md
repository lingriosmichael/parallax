# PAX-121 · Aiming turret (D-197 (5))

**Status:** Approved 2026-10-24. The developer picked these mechanics from a list of thirteen: "1 ... 6 ... 7 ... 9 ... 10".
**Phase 1 size:** Lite. Each builds on an existing path (the RoomTrap timing, the spinner, the carry, the push, the arrow lane), as
D-187's did.
**Decisions:** D-040, D-091, D-187, D-197.

## 1. What to build

1. **`SoloRoomElementKind.Turret`** (appended): a turret hosted in a solid, on a Periodic cycle.
   - **Aim** (`aimTicks`): a thin, harmless line tracks the cat's centre.
   - **Lock** (`lockTicks` ≥ 6): the line stops and flickers. This is the tell.
   - **Fire** (`fireTicks`): a lethal beam runs along the locked line to the first fixed solid.
   - **Rest.**
2. **Runtime:** `TurretTrap : RoomTrap`.
   - The aim reads the cat's body position in the room step (deterministic).
   - The beam's end is a raycast against the reality's solids.
   - The kill is an oriented box test.
   - A rewind restores the locked angle by value (`TrapSnapshot.ExtraFloat`) and the phase by formula.
3. **Validator:** lock ≥ 6, a cooldown that covers the cycle, the turret hosted in a fixed solid, and periodic slack.
4. **Tests:** the aim and lock math, the kill only in the fire phase, the restore, and a fixture route (move after the lock).
