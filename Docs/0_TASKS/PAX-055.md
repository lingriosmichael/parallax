## 1. Why

"Arrows from the left and right when you jump" is one of the requested troll patterns. The
kit has no projectile. Arrows must stay deterministic and learnable: same trigger, same flight,
visible before they can kill.

## 2. What to build

1. **`ArrowLauncher`** trap (D-055 trigger source and repeat mode, like every trap): a launcher
   body in a wall (disguised as wall, D-056 (4)) that fires one or more arrows along a fixed
   direction (left or right, and up/down for gravity-flipped rooms) at a fixed speed
   (units/tick). Optional **burst**: N arrows, S ticks apart.
2. Arrow position is a pure function of ticks since fire (no Rigidbody physics). Kill test
   overlaps the arrow's tick pose with the cat collider, like `MovingTrap` Hazard.
3. An arrow stops and disappears at the first fixed geometry on its line (computed at layout
   time from data, not a runtime raycast) or at the room's kill bounds.
4. **Reveal:** on fire the launcher shows a tell (opens / changes colour) and the first arrow
   leaves the launcher ≥ D-057's 6 ticks later; an arrow is visible from the moment it leaves.
5. **New trigger option "on jump"**: an Overlap trigger box that only counts while the cat is
   airborne and rising (reads the motor's grounded/vertical state for that tick). This is the
   "when jumping" pattern. If the trace shows this needs motor changes, stop and report.
6. Room reset (D-041): no arrows alive, launcher re-armed, burst counters cleared.
7. **Validation:** D-056 (1) slack for dodging (by stopping, jumping or crouch-under geometry)
   is computed from arrow speed and the cat's measured numbers; arrow lines never pass through
   the checkpoint's respawn pose (no spawn kill).

## 3. Rules

Deterministic ticks only; no `Time.time`, no physics for arrows · kills only via `RoomDeath` ·
novice-tier rules apply until PAX-057 adds tiers · frozen code untouched.

## 4. Tests (EditMode)

1. Arrow pose at tick t matches `launcher + dir × speed × (t − lead)`; identical across two runs.
2. First arrow cannot overlap anything before lead ticks after fire.
3. Arrow stops at the first geometry on its line; never passes through a wall.
4. Burst spacing exact; reset clears all arrows mid-burst.
5. On-jump trigger fires only while airborne-rising; not while grounded or falling.
6. Validator rejects a line that crosses the respawn pose, and a dodge window below slack.

## 6. Out of scope
