# PAX-067 · Release build: signed AAB and build checks

**Status:** Draft.
**Phase:** Solo v1, Phase G
**Depends on:** PAX-066
**Decisions:** D-033 (MCP not in builds), D-064

---

## 1. Why

Google Play needs a signed Android App Bundle meeting its current target API level, and the
release build must contain no dev tooling.

## 2. What to build

1. **`PARALLAX/Build/Release AAB`** Editor script: builds IL2CPP ARM64 AAB, non-development,
   scenes from Build Settings (Menu first, then the 50 levels; no sandboxes), output outside
   the repo. Reads version name/code from a `BuildVersion` asset; version code auto-increments
   and is committed.
2. **Build checks** (run by the script, fail the build on any):
   - no `Parallax.DebugTools` or MCP-for-Unity assembly in the build report (D-033);
   - no `Sandbox_*` or `Level_Solo01` scene included;
   - every `LevelListConfig` scene included;
   - `Development Build` off, script debugging off;
   - merged manifest contains `VIBRATE` (PAX-065) and the billing permission from Unity IAP.
3. **Developer-only settings (by hand, never by an agent; ProjectSettings is off-limits):**
   package name, app name, keystore (stored **outside** the repo; passwords never committed or
   logged), target API level = Google Play's current requirement (check at the time; third-party
   guides report API 36 required from 31 Aug 2026), minimum API, splash.
4. Output: AAB size and the build report summary.

## 3. Rules

`manage_build` only via this ticket · the keystore and passwords never enter the repo, a log or
the review file.

## 4. Tests (EditMode)

The check functions run against fake build reports: each forbidden assembly/scene fails;
a clean report passes. Version-code increment is monotonic.

## 5. YOU — UNITY EDITOR

Set the Player settings listed in 2.3. Run the build; it passes the checks and produces an AAB.
Don't install it yet. Performance and install behaviour are **unverified (Phase H)**.

## 6. Required output

As `CLAUDE.md` (never paste keystore details), review file `pax067_review.txt`.
