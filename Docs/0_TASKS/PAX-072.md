# PAX-072 · iOS port (outline)

**Status:** Outline only. Phase I, after PAX-071. Split into real tickets when it starts.

- Mac + Xcode, Apple Developer Program membership, iOS build target module installed (package
  approval).
- StoreKit via the same Unity IAP product; **Restore purchase** is mandatory on iOS (already in
  the UI from PAX-066).
- Haptics: `IHaptics` iOS implementation (UIFeedbackGenerator via a small native plugin, or
  Handheld.Vibrate fallback).
- Safe areas and Dynamic Island, landscape-left lock, ProMotion (120 Hz) vs 60 Hz tick
  assumptions: the simulation is tick-based, but check rendering interpolation.
- App Store listing, privacy nutrition label, age rating, review.
- Device session on an iPhone (PAX-037 equivalent).
