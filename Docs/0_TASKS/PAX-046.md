## 1. Goal

`Level_Solo01` still uses kit v1 only, on mostly flat floors. Rebuild its four rooms so they play
like Level Devil: **the room mutates as you solve it**, the obvious move is the one that kills
you, and the solution is learnable after one death.

- Use kit v2 (chains, moving traps, repeats) across the level.
- Add **real platforming**: elevated platforms, gaps and height changes, not just a flat run.
- **Disguise** every betrayal until it fires.
- Raise difficulty through **stacking and disguise**, not through tighter jumps.

**Layout data only.** No runtime or setup code changes. If a room needs something the kit can't
do, it goes on the kit-gap list (§11) and the room is designed without it.

## 2. What stays true

## 3. Decision D-056 (commit before implementation)

```
### D-056 · 2026-09-22 · Accepted
**Decision:** Rooms v3 layout rules for trap kit v2 (PAX-046).
(1) Timing slack. Every survive case that depends on timing (periodic windows, chain delays,
moving traps, collapse delays) leaves at least 12 ticks (0.2 s at 60 Hz) of slack beyond the
minimum the cat needs, computed from the measured movement numbers. Touch input on a phone
cannot be tighter than that.
(2) Platforms. Every jump the solution requires is a RequiredJump in layout data and passes the
reachability contract (D ≤ 0.75 reach), including jumps between platforms at different heights.
Difficulty comes from what the room does, never from a jump near the limit.
(3) Moving solids. A moving Solid's swept path (authored pose to authored pose + offset, full
size) overlaps no fixed geometry; touching is allowed. A cat is only ever crushed against
geometry the layout names as the crush partner.
(4) Disguise. Before it fires, a betraying trap looks like ordinary level geometry or like
nothing: collapsing floors and moving Solids use the floor/wall look, hidden spikes are
invisible, chained traps have no visible trigger. Honest hazards (visible spikes, visibly
moving hazards) are allowed and are not counted as betrayals.
(5) Learnability. After a death the player can see what killed them: every betrayal leaves a
visible result (a gap, revealed spikes, a moved block) until the room resets.
**Why:** Kit v2 lets rooms mutate (D-055). These rules keep the mutation fair on a phone:
enough slack for touch, platforming that is never the hard part, no physics surprises, and
deaths that teach (D-040, D-053).
```

## 4. Room requirements

Per room:

- A **one-sentence shape**: setup → obvious route → betrayal → learned solution (vision §4).
- **4–6 betrayals**, at least **2 of them kit v2** (chained, moving, or repeating).
- At least **2 required platform jumps** with a height change (up or down), recorded as
  `RequiredJumps`.
- At least one **"false safety" moment**: a spot that looks safe (a platform, a gap already
  crossed, a trap that already fired) that is itself the next betrayal, or triggers it.
- A designer estimate of **deaths for a first-time player: 3–6**.

Across the level:

- At least one **chain of 3+ links**, one **moving Solid** (crush or rising floor), one **moving
  Hazard**, one **Periodic** trap, one **Rearm** trap, and one **gravity-flip** use.
- Difficulty **rises** room to room; Room 4 combines what the first three taught.
- Keep PAX-044 betrayals that work; replace the weakest. Say which and why.

## 5. Design notes

- **Chains are the core tool.** The best Level Devil moments are "I dodged it, and dodging it
  was the trigger". A chain whose source is the player's survive move is worth more than a new
  trap type.
- **Rearm and Periodic are for rooms the player crosses more than once**, or where waiting is the
  obvious move. A rhythm the player can read is fair; a rhythm hidden behind a disguise is not.
- **Moving Solids** are strongest as floors that leave (drop, slide away) or walls that close.
  Mind the launch when a fast Solid stops under the cat (PAX-045: 9.7 u/s up launched the cat).
- **Platforms carry the trolls.** A platform that collapses, rises into spikes, or triggers a
  block is the natural v3 betrayal.
- **No sideways carrying platforms** (kit gap). Vertical Solids carry the cat; horizontal ones push.

## 6. Layout data

- All changes in `SoloRoomsLayout`: elements, settings, openings, hazard roles, `RequiredJumps`,
  `RequiredSteps`.
- Platforms are `Floor` elements at height (or `Wall` where they are side geometry). Every
  platform edge that the reachability contract uses is an element edge, so a moved platform
  breaks the test instead of the record.
- Crush partners: name them in the layout (a `SourceName`-style field or a naming convention the
  test can read; propose which in Phase 1).

## 7. Out of scope

New trap types or kit changes · runtime or setup code · level-complete screen · death counter UI
· art (PAX-A06/A07) · device testing · Reality B · co-op · new rooms beyond four.

## 8. Tests (EditMode)

Extend `SoloRoomsLayoutTests` (reflection, as today) or add a new file under `Tests/EditMode`:

1. **All four rooms pass `TrapLayoutValidator`.**
2. **Kit v2 coverage:** each room has ≥ 2 kit v2 traps; the level has every feature in §4.
3. **Platform jumps:** each room has ≥ 2 `RequiredJumps` with a height change; all pass the
   existing reachability contract.
4. **Periodic windows (D-056 (1)):** for every Periodic hazard on the route, the safe window
   (period − cooldown) ≥ crossing ticks + 12, where crossing ticks = (hazard width + cat width) /
   0.10 u/tick, unless the crossing is a required jump (then use the jump's air time).
5. **Moving Solid paths (D-056 (3)):** the swept box of every moving Solid overlaps no fixed
   geometry element (touching allowed), except its named crush partner, which it may only touch.
6. **Disguise (D-056 (4)):** every CollapsingFloor and moving Solid uses the floor/wall look;
   every chained or periodic trap has no trigger box; hidden spikes are not rendered before
   reveal. Check from layout data (settings, kinds, secondary sizes); report anything the data
   cannot express.
7. **Regression:** all existing `SoloRoomsLayoutTests` rules (1–8, containment, separation,
   reachability) still pass on the new rooms. If a rule no longer fits a v3 room, stop and report;
   do not weaken it.

**Baseline:** 266 (PAX-045). Report baseline → new.

## 13. Acceptance (Editor)

1. **Every kill case kills and every survive case survives**, 3 times each, as in the Phase 1
   table.
2. **Every required jump** is makeable on the first or second try by the designer.
3. **Disguise:** before firing, no betrayal is visible as a trap in the greybox.
4. **Learnability:** after each death the cause is visible on screen until reset.
5. **No soft-locks:** no rearm, periodic or moving state leaves the door unreachable.
6. **Chains, moves and repeats** behave as in the table; no cat pushed through geometry.
7. **Reset:** dying mid-chain, mid-move and mid-cycle restores the room completely.
8. **Difficulty:** designer run records deaths per room; rooms get harder 1 → 4.
9. **Console:** known noise only.
