   - `public static float SpeedForHeight(float height, float gravityStrength)` = sqrt(2 * g * h).
     Returns 0 for non-positive inputs. Pure C#, no UnityEngine.

2. CREATE Assets/_Game/Tests/EditMode/JumpMathTests.cs   (namespace Parallax.Tests)
   - NUnit tests: known value (h=2, g=30 → sqrt(120)), zero height → 0, negative inputs → 0.

   - Add, with tooltips and defaults: jumpHeight = 3.2 (world units), coyoteTime = 0.10 s,
     jumpBufferTime = 0.12 s, groundProbeDistance = 0.05, groundNormalThreshold = 0.7,
     groundMask (LayerMask, default Everything).
   - Keep existing fields and defaults unchanged.

4. MODIFY Assets/_Game/Gameplay/Player/CatMotor2D.cs
   - Ground detection each FixedUpdate: `body.Cast(down, filter, hits, groundProbeDistance)`
     with a ContactFilter2D using config.groundMask (useTriggers false). Grounded if any hit has
     `Dot(hit.normal, -down) > groundNormalThreshold` AND the cat is not moving against gravity
     (fall >= -0.01). Reuse a preallocated RaycastHit2D buffer (no per-frame allocations).
   - Public read-only `IsGrounded`.
   - Coyote timer: set to coyoteTime while grounded, counts down (by fixedDeltaTime) otherwise.
   - Jump buffer: `SetCommand` LATCHES a JumpPressed edge by setting the buffer timer to
     jumpBufferTime; later SetCommand calls with JumpPressed = false must NOT clear it.
     Buffer counts down in FixedUpdate.
   - Jump: if buffer > 0 and coyote > 0 → fall = -JumpMath.SpeedForHeight(jumpHeight, gravity.Strength);
     then set both timers to 0 (prevents double jumps).
   - Timers use Time.fixedDeltaTime only. Never Time.time / Time.deltaTime.
   - No body rotation (PAX-010). No variable jump height (JumpHeld unused for now).
   - Keep all PAX-007 behaviour (gravityScale forcing, config-missing error, facing flip).

5. MODIFY Assets/_Game/Gameplay/Input/KeyboardCatInput.cs
   - JumpPressed = Space, W or UpArrow `wasPressedThisFrame`; JumpHeld = any of them `isPressed`.

6. CREATE Assets/_Game/Editor/CatPlayerSetup.cs   (namespace Parallax.Editor)
   - Menu item: `PARALLAX/Setup/Configure Cat Player`.
   - Idempotent (running it twice changes nothing the second time). Uses AssetDatabase and
     PrefabUtility.LoadPrefabContents / SaveAsPrefabAsset / UnloadPrefabContents. Never writes YAML text.
   - Steps:
     a. Ensure Assets/_Game/Data/Cat_NoFriction.physicsMaterial2D exists

     b. Ensure CatMotorConfig_Default exists in Assets/_Game/Data; create with defaults if missing.
     c. Open Cat_Player.prefab contents. On the root ensure GravityReceiver, CatMotor2D,

     d. Save and unload the prefab. Log one summary line listing what changed (or "already configured").
     e. If the prefab or the Visual child is missing, log a clear error and stop without saving.
