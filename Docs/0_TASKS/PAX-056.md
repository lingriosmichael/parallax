# PAX-056 · Trap kit v3b: carrying platforms

**Status:** Draft. Architect refreshes the read list and trace after PAX-055 is committed.
**Phase:** Solo v1, Phase C
**Depends on:** PAX-055
**Decisions:** D-055 (3) moving Solid, D-056 (3) swept path and launch, D-048, D-052, D-064
**Implementer reads first:** `MovingTrap` (Solid kind), `CatMotor2D` grounding

---

## 1. Why

Platform-to-platform jumping and "the platform you're standing on betrays you" both need
platforms that move **sideways** and carry the cat. Today a moving Solid pushes and crushes and
launches upward; a cat standing on a sideways Solid slides off because nothing transfers the
platform's motion.

## 2. What to build

1. **Carry:** when the cat is grounded on a moving Solid (the grounding cast hits it), the
   cat's position is offset each tick by the Solid's tick delta along the platform's surface
   (horizontal in both gravities). The motor applies it before its own movement, so the
   player's input stays relative to the platform. Leaving the platform (jump or walk off) keeps
   the platform's horizontal velocity for that jump — **decide in the trace** whether to keep it
   (Celeste-style) or drop it; default: keep, it reads as fair.
2. **Looping platforms:** `MovingTrap` Periodic mode (D-055 (2)) already allows go-and-return;
   add a "ping-pong forever from room start" preset in data so a steady platform path needs no
   trigger.
3. **Betrayal variants in data:** a carrying platform can be combined with existing kit (chain a
   collapse at the end of its path, speed up after N ticks via a second MovingTrap segment).
   No new behaviour beyond carry; just make sure chains work on it.
4. **Validation:** jumps between moving platforms are RequiredJumps checked at the worst tick
   of the window the solution uses (D-056 (2)); carry never pushes the cat into fixed geometry
   except the named crush partner (D-056 (3)).

## 3. Rules

Carry uses tick deltas of the Solid's authored path, never physics friction · gravity-up carry
works identically (D-048) · `CatMotor2D` changes are minimal and listed · frozen code untouched.

## 4. Tests (EditMode)

1. A cat standing still on a platform moving +x by d per tick moves +x by d per tick.
2. Same with gravity up.
3. Walking on the platform: cat displacement = input displacement + platform delta.
4. Jumping off keeps (or drops, per decision) the platform's horizontal velocity.
5. Standing next to (not on) a moving platform: no carry.
6. Validator rejects a required jump that only works at a lucky tick.

## 5. Allowed files

`CatMotor2D.cs` (carry hook), `MovingTrap.cs`, layout element/builder/validator files; new files
under `Core`, `Gameplay`, `Tests/EditMode`.

## 6. Out of scope

Vertical carry beyond D-056 (3)'s existing launch rule · conveyor belts · rotating platforms.
