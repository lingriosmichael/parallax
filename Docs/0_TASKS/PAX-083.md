## 4. Outcomes, decided now

- **(a) An item is done within §5's rules.** Done; no stop.
- **(b) An item would need runtime code, a layout change, or a change to an existing route result or pin.** Skip that item and report why, with the smallest fix. No stop.
- **(c) A PAX-075 nit can't be found.** Report where you looked, and skip it. No stop.
- **(d) A `Retreat` route doesn't pass as Recovers** (the cat dies, the room doesn't complete, or nothing visibly changes). Don't change the layout. Leave that one unclaimed, and record it in the report. No stop.
- **(e) Item 9 is runtime code, and the launch speed at the first jump tick is under 9.3 u/s** (a margin under 0.3). **Stop.** Report the numbers and propose a fix. A runtime change needs its own ruling and D-085.
