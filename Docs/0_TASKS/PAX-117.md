# PAX-117 · Conveyor floors (D-197 (1))

**Status:** Withdrawn 2026-10-24 (D-199). The developer: "remove the sliding belt entirely from the trapkit. I dont like it at all."
The code was built and then removed; nothing here is to be built again. (Approved earlier that day from a list of thirteen: "1 ... 6
... 7 ... 9 ... 10".)
**Phase 1 size:** Lite. Each builds on an existing path (the RoomTrap timing, the spinner, the carry, the push, the arrow lane), as
D-187's did.
**Decisions:** D-040, D-091, D-187, D-197.

## 1. What to build

1. **`SoloRoomElementKind.Conveyor`** (appended): a static solid floor (or ceiling) that carries a cat standing on it at
   `unitsPerTick`. The sign gives the direction; the speed stays below the cat's run, so walking against a belt always moves you.
2. **Reversal**, set in `ConveyorSettings`:
   - none;
   - every `reverseTicks` from the room's first tick;
   - on its trigger (Overlap or Chain), after the delay, for `reverseHold` ticks, then back.
   It's a function of ticks (D-091). The belt's look shows the direction: stripes that scroll the way it carries, plus a tint
   when it's reversed. The look is a placeholder.
3. **Runtime:** `ConveyorTrap : RoomTrap` on the solid. `RoomManager.CarryOnMovingFloor` applies its displacement through
   `CatMotor2D.ApplyCarry`, the same path Carry movers use.
4. **Validator:** it counts as fixed geometry; |speed| ≤ 0.75 × the cat's run per tick; reverseTicks ≥ 30.
5. **Tests:** carry and reversal math, a rule, and a fixture room (the belt carries you onto spikes when you stand still; the
   reversal throws you back).
