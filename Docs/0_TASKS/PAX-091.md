# PAX-091 · Coverage search sees every way up

**Status:** Approved. Runs after PAX-060 half A, **before half B**. **Phase 1 size: Lite.**
**Depends on:** PAX-060a committed. **Decisions:** D-074 (trigger coverage), D-080 (surface coverage), D-086 (spears), D-088 (geysers), D-089 (vines).

## 1. Why

PAX-060 half A found that the coverage search (`TriggerCoverage.cs`, the approach search, surface coverage) only knows layout surfaces and walking or jumping between them. It can't see a geyser launch, a vine climb or a stuck spear as a floor. So hazards reached only that way are judged from the wrong side (L013's Spikes_D2), and layouts get bent to fit the rule (L012's orb boxes). Half B uses all three in every level.

## 2. What to build (validator only)

1. The approach search gains three edges: **launch** (from a geyser vent, bounded by its envelope, D-088), **climb** (a vine's span, and a leap from any point of it), **stuck spear** (a floor from the tick it sticks, for triggers after that spear's trigger).
2. **Surface coverage per storey**, like trigger coverage (PAX-059 R-1 Q3).
3. **Closed pits:** a drop can't pass through a pit whose floor is closed at that point.
4. No threshold changes; no runtime code.

## 3. Rules and tests

- Every existing coverage result for L001–L013, the Trap Lab and the fixtures stays **identical**, or changes only where a PAX-060 workaround was made (list them). A new false *pass* on an existing level is a stop.
- Red-first fixtures: a hazard reachable only by a launch, by a climb, by a stuck spear; a surface on a second storey; a drop through a closed pit.
- Report whether L012's orb boxes and L013's Spikes_D2 fix would now pass in their original, natural form (they aren't reverted in this ticket).

## 4. Allowed files

`TriggerCoverage.cs`, new `TriggerCoverage.Edges.cs` (§11 Q1), `LevelLayoutValidator.Surfaces.cs`, the coverage fixtures, new tests, `07_DECISIONS.md` (a note on D-074/D-080), `08_V1_ROADMAP.md`.

## 11. Rulings (Phase 1, 2026-09-27)

**Baseline:** 1,195 EditMode tests, 0 failures (the implementer's batched run, with the ~7 overlapping names noted). Fine for now; PAX-092 will give a clean full-run number.

- **Q1 · `TriggerCoverage.Edges.cs`:** approved, added to §4.
- **Q2 · Stuck spear as floor:** approved as proposed. The shaft counts for every trap except the spear itself, its chain root and that root's chain. Static and strictly stricter; no replay ordering.
- **Q3 · Vine leap:** approved. An ordinary jump (full rise, flat reach, D-089's leap launch) from any height on the vine, including the top stop. Also add a release/drop from any height on the vine (fall reach). Only adds reach.
- **Q4 · Closed pits:** the general fix, but only **fixed** solids block a drop (`IsFixedSolid`: Floor, Wall, PitBottom, Ceiling). CollapsingFloor and FakePlatform do **not** block, since they may be gone in a real run. Keep that the conservative direction.
- **Q5 · Down geysers:** include them, from ceiling surfaces, in rooms that contain a gravity flip. Level 16 will need it.
- **Q6 · Surface coverage per storey with both approach sides:** approved; list every change.

**The fallback-shift risk:** don't auto-stop. For every existing danger (L001–L013, Trap Lab, fixtures) whose result changes, list before → after. If one **newly passes**, give a one-line reason why the side it no longer checks is truly unreachable, and the Architect rules. A new **error** on an existing level: report it, don't change the layout.
