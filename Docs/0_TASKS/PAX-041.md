## OBJECTIVE

Add a hazard that kills the cat on touch, and make every death reset the current room: the cat
respawns at the room's checkpoint and every trap and room-owned anchor in that room returns to its
declared initial value, in ≤ 0.75 s, with no fade, screen or reload.

## CONTEXT

- `Docs/07_DECISIONS.md`: D-041 (death resets the room), D-050 (room model), D-024 (anchor
  requests, idempotency), D-032 (respawn gravity).
- `Docs/02_ARCHITECTURE.md` §7 (anchors), §9 (transport, authority), §11 (checkpoints, as built
  PAX-036).
- As built by PAX-036/039/040: `CheckpointManager.Respawn(observer)`, `CatRespawn.RespawnAt`,
  `FallResetVolume` (+ `CheckpointPolicy.FallResets`), `RoomManager` (`soloReality`, current room),
  `RoomSetup`, `DebugPanel`.
- Today only fall volumes kill, and a fall only respawns the cat. After this ticket, every death in
  the solo reality goes through one path.

**Create — `Parallax.Core` (pure C#, no MonoBehaviours):**

- `Core/Rooms/TrapState.cs` — `enum TrapState { Armed, Fired }`.
- `Core/Rooms/DeathCause.cs` — `enum DeathCause { Fall, Hazard }`.
- `Core/Rooms/IRoomResettable.cs` — `int RoomId { get; }`, `void ResetToInitial();`
- `Core/Rooms/RoomResetRegistry.cs` — per-room registration and reset planning:
  - `bool Register(IRoomResettable item)` / `bool Unregister(IRoomResettable item)` (false on
    duplicate / unknown).
  - `bool RegisterAnchor(int roomId, AnchorId id, float initialValue)` (false if that anchor is
    already bound to any room; an anchor belongs to at most one room).
  - `RoomResetResult Reset(int roomId, List<AnchorReset> anchorResetsOut)` — calls
    `ResetToInitial()` once on every item registered to `roomId`, fills `anchorResetsOut` with
    `(AnchorId, InitialValue)` for every anchor bound to `roomId`, and touches nothing registered
    to any other room. Returns counts (traps reset, anchors reset).
- `Core/Rooms/DeathTickGuard.cs` — `bool TryAccept(ObserverId observer, int tick)`: true for the
  first death of that observer on that tick, false for any further one on the same tick.

**Create — `Parallax.Gameplay`:**

- `Gameplay/Rooms/RoomDeath.cs` (on `Systems`) — the single death path.
  `void Kill(ObserverId observer, DeathCause cause)`:
  1. Ignore cats not driven by `LocalHuman` (Echo and Inactive never die).
  2. If the cat is **not** in `RoomManager.soloReality`, fall back to today's behaviour
     (`CheckpointManager.Respawn` only) and return. Frozen co-op code keeps working unchanged.
  3. Drop the call if `DeathTickGuard` rejects it (one death per observer per tick).
  4. Respawn the cat at the current room's checkpoint via `CheckpointManager.Respawn`. Room id =
     checkpoint id (D-050); if the current room id and the checkpoint progress disagree, log an
     error with both values and use the room id.
  5. `RoomResetRegistry.Reset(currentRoom, …)`.
  6. For each anchor reset, if `transport.IsSessionAuthority`, send an `AnchorRequest` with the
     initial value as an **absolute target**, origin `System`, and a fresh sequence from the
     existing System-origin `EventSequencer`. Never call `ApplyReplicated`, never write
     `AnchorRegistry` directly. If not session authority, log an error and skip (co-op later).
  7. Raise `event Action<DeathInfo> Died` (observer, cause, room, tick, traps reset, anchors reset).
- `Gameplay/Rooms/Hazard.cs` — a trigger `BoxCollider2D` zone on its reality's layer. Each tick on
  `ObserverSet.Stepped` it runs an `OverlapBox` with its reality's mask (overlap query, not trigger
  callbacks) and calls `RoomDeath.Kill(observer, DeathCause.Hazard)` for an overlapping cat.
  Always lethal while enabled; it has no armed/fired state and no room id (death always resets the
  **current** room). PAX-042 traps will enable and disable hazards.
- `Gameplay/Rooms/RoomTrap.cs` — abstract base for traps: serialized `roomId` and
  `initialState` (`TrapState`), `State` property, registers with `RoomResetRegistry` on enable and
  unregisters on disable, `ResetToInitial()` sets `State = initialState` and calls a protected
  `OnReset()`. `protected bool IsRoomLive` (true only while `roomId` is the current room). A trap
  must never fire while its room is not live.
- `Gameplay/Rooms/RoomAnchorBinding.cs` — serialized `roomId`, `anchorId`, `initialValue`; binds
  the anchor to the room through `RegisterAnchor`. It does **not** register the anchor with
  `AnchorRegistry`; the anchor's owner does that.

## REQUIREMENTS

- A `LocalHuman` cat touching a hazard dies; a fall into a fall volume also dies. Both go through
  `RoomDeath.Kill`.
- Death respawns the cat at the current room's checkpoint with the checkpoint's gravity (D-032).
- Every `RoomTrap` in the current room returns to its initial state; traps in other rooms are
  untouched.
- Every anchor bound to the current room gets a new absolute-target request from the session
  authority, origin `System`, fresh sequence.
- At most one death per observer per tick.
- Death beats a door touched on the same tick, independent of handler order.
- Traps never fire while their room is not live.
- The cat accepts input on the first physics tick after the death tick (well under 0.75 s).
- Echo and Inactive cats never die; cats outside `soloReality` keep today's fall-respawn behaviour.
- EditMode total = previous ticket's total + the new tests, zero failures.

## ACCEPTANCE TEST (Editor only; device checks wait for PAX-037)

Clear the console, open the debug panel (DBG).

1. **Hazard.** Walk right into `Hazard_0`. The cat reappears at checkpoint 0 immediately, no fade,
   and moves as soon as you press a key. Panel: `Last death: Hazard · room 0 …`.
2. **Jump it.** Jump over `Hazard_0`; nothing happens.
3. **Trap reset.** Walk left into `DebugTrap_0`: it turns orange, `FIRED`. Walk into `Hazard_0`:
   the trap is back to grey, `ARMED`. Panel shows `reset 1 traps`.
4. **Fall.** Walk off the left edge (x < −9). Same result as step 1, cause `Fall`.
5. **Anchor reset is a new request.** Press "Debug anchor 0<->1" so anchor 65535 shows value 1.
   Note its revision. Die. The anchor table shows value 0 and a **higher** revision.
6. **With latency.** Set the latency slider to 300 ms, set anchor 65535 to 1, die. The cat is back
   in control at once; the anchor returns to 0 about 300 ms later. Set latency back to 0.
7. **Completed room is not reset.** Stop and replay. Fire `DebugTrap_0`, jump `Hazard_0`, touch
   `Door_0` → room 1 at checkpoint 1. Walk into `Hazard_1`: the cat respawns at checkpoint 1, and
   `DebugTrap_0` stays `FIRED`.
8. **Non-live trap.** Stop and replay. Without touching the trap, go through `Door_0`, then walk
   back left (jump `Hazard_0`) onto `DebugTrap_0`. It stays `ARMED`.
9. **Console.** No errors or warnings other than the known noise listed in `CLAUDE.md`.
