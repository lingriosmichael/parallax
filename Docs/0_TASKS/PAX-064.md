# PAX-064 · Audio: mixer, ambient bed, cues, volume wiring

**Status:** Draft. Architect refreshes after Phase D.
**Phase:** Solo v1, Phase F
**Depends on:** PAX-054 (settings), all trap kits (PAX-055/056/058)
**Decisions:** Vision §9, D-062 (7), D-064
**Implementer reads first:** trap base class and fire points, `RoomDeath` (`Died`, kill),
`CatRespawn`, door completion, `GameSettings`/`SettingsStore`.

---

## 1. Why

Every betrayal should be heard as well as seen (Vision §9). Volumes are already stored
(PAX-054) and need wiring.

## 2. What to build

1. **Single trap-fire event:** if traps don't already raise one, add `TrapFired(trapId, kind,
   worldPos, tick)` to the trap base, raised once at the fire tick (D-055 (1) definition). This
   event is also what PAX-065 uses.
2. **`AudioMixer`** asset with groups Music, Sfx, UI; exposed volume params. Settings 0–1 map to
   dB with `20·log10(v)`, and 0 → −80 dB.
3. **`AudioCueBank`** (`ScriptableObject`): one slot per cue: per trap kind fire, death, respawn,
   door/level complete, jump, land, flip, UI tap/back. Each slot: clip(s), volume, pitch jitter
   range (presentation only; never affects gameplay), max simultaneous.
4. **`GameAudio`** (`Parallax.Gameplay`, wired by the composition root, no singleton): listens to
   the events above, plays cues through pooled `AudioSource`s; ambient bed loop per level (bed
   chosen in `LevelLayout` data, default one bed for all). Pausing (PAX-054) pauses Sfx, keeps a
   ducked bed.
5. Missing clip → silent, logged once per slot. Audio never gates gameplay timing.
6. Clips are provided by the developer (licence recorded in `Docs/Audio/Licences/`); import
   settings: bed streaming/Vorbis, short Sfx decompress-on-load.

## 3. Rules

No new packages (built-in Unity audio only) · audio is presentation: removing `GameAudio` must
not change any test · no `Time.time`-driven gameplay.

## 4. Tests (EditMode)

1. Each trap kind raises `TrapFired` exactly once at its fire tick (chained, periodic, rearm).
2. Volume mapping: 1 → 0 dB, 0.5 → ≈ −6 dB, 0 → −80 dB.
3. Cue dispatch maps each event to its slot (fake player, no real audio).
4. Max-simultaneous limit respected.

## 5. Allowed files

Trap base file (event only), new files under `Core`, `Gameplay`, `Data`, `Audio`, `Editor/Setup`,
`Tests/EditMode`, level template setup script.

## 6. Out of scope

Music composition · adaptive music · haptics (PAX-065).
