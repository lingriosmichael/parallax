OBJECTIVE
One human switches control between Cat A and Cat B with an on-screen SWITCH button (Tab in
the Editor). The switch swaps drivers and cameras together. A dev-only debug panel shows both
Observers' state and can show the other reality picture-in-picture. When done, Phase 3's
exit criterion passes on the phone: switch between two cats in two visibly different
realities, each colliding only with its own world.

  code that assigns drivers or enables/disables Observer cameras.**
  - Serialized: `ObserverSet observers`, `CatInputRouter router`.
  - `ObserverId Active { get; }`.
  - `event Action<ObserverId, ObserverId> Switched` (from, to). Local-only, never networked.
  - `Initialize(ObserverId startActive)`: target → `new LocalHumanDriver(router)`, other →
    `new InactiveDriver()`, then cameras.

       Camera component disabled (component, not GameObject);
    4. raise Switched.

  - Switches are requested from Update, so they always land between fixed ticks. Note that in
    a code comment.

  ### D-023 · <date> · Accepted
  **Decision:** (1) `SoloSwitchController` is the only runtime code that assigns Observer drivers or enables Observer cameras; bootstrap delegates to it and the PAX-014/015 dev toggles are removed. (2) On-screen controls declare `ITouchReservedRegion`s; a touch that begins inside one is never claimed by movement input. (3) Debug PiP renders the inactive Observer's camera into a corner viewport; dev builds only, default off.
  **Why:** Two owners of drivers/cameras can leave both cats LocalHuman on one router, or show one reality while driving the other. Without reserved regions, tapping SWITCH also starts the stick or jump.
  **Supersedes:** RealityViewDebugToggle and ObserverDriverDebugToggle (PAX-014/015).
