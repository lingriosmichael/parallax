TITLE: GravityReceiver + CatMotor2D — per-cat gravity and gravity-relative horizontal movement
PHASE / GATE: Phase 2 (One ugly cat) / Gate 2

OBJECTIVE
The placeholder cat falls under its OWN gravity (not Physics2D.gravity) and moves left/right
along the axis perpendicular to that gravity, driven by a CatCommand from a temporary keyboard input.

- 02_ARCHITECTURE.md §4.1 (CatCommand), §5.1 (movement input).

CLAUDE — CODE
Allowed files (create unless noted; nothing else):
1. Assets/_Game/Core/Input/CatCommand.cs
   - `public struct CatCommand` exactly as in §4.1 (Move, JumpPressed, JumpHeld, InteractPressed,
     InteractHeld, static None). Namespace `Parallax.Core`. No UnityEngine types needed.
2. Assets/_Game/Gameplay/Player/GravityReceiver.cs
   - As in §6: initialDirection (default down), strength (default 30), turnSpeedDegPerSec (default 360),
     Direction, Strength, SetTargetDirection(Vector2), FixedTick(float dt).
   - Namespace `Parallax.Gameplay.Player`.
3. Assets/_Game/Gameplay/Player/CatMotorConfig.cs
   - ScriptableObject with `[CreateAssetMenu(menuName = "PARALLAX/Cat Motor Config")]`.
   - Fields: maxSpeed (default 6), acceleration (default 60), deceleration (default 80),
     maxFallSpeed (default 20). Tooltips on each.
4. Assets/_Game/Gameplay/Player/CatMotor2D.cs
   - `[RequireComponent(typeof(Rigidbody2D), typeof(GravityReceiver))]`.
   - Serialized: `CatMotorConfig config`, `Transform visual` (the child to flip).
   - `public void SetCommand(CatCommand cmd)` stores the latest command.
   - Awake: cache components; force `Rigidbody2D.gravityScale = 0`. If config is missing,
     log an error with the GameObject name and disable the component (do not silently continue).
   - FixedUpdate: gravity.FixedTick(dt); compute down/right as in §6; decompose linearVelocity into
     along/fall; along moves toward Move*maxSpeed using acceleration (deceleration when Move is ~0);
     fall += Strength*dt, clamped to maxFallSpeed; write back linearVelocity. Also re-assert
     gravityScale == 0 (log a warning once if something changed it).
   - Flip: when |Move| > 0.01, set visual.localScale.x to +|x| (Move > 0) or -|x| (Move < 0).
     Keep facing when Move is 0.
   - Use `Rigidbody2D.linearVelocity` (Unity 6). No deprecated APIs.
5. Assets/_Game/Gameplay/Input/KeyboardCatInput.cs   (temporary, Editor testing)
   - Uses the Input System package (`UnityEngine.InputSystem.Keyboard.current`), NOT legacy UnityEngine.Input.
   - Update: Move = -1 for A/LeftArrow, +1 for D/RightArrow, 0 for none or both. Handle Keyboard.current == null.
   - Passes a CatCommand to CatMotor2D.SetCommand every frame. Jump/Interact fields left false.
   - `[RequireComponent(typeof(CatMotor2D))]`.
6. MODIFY: Assets/_Game/Gameplay/Parallax.Gameplay.asmdef
   - Add `Unity.InputSystem` to references (keep `Parallax.Core`). No other changes.

Before writing code, READ (do not modify) Packages/manifest.json and confirm `com.unity.inputsystem`

REQUIREMENTS
- gravityScale is 0 at runtime and is forced by CatMotor2D.
- Gravity is GravityReceiver.Direction * Strength, applied by the motor only.
- Horizontal movement is along the axis perpendicular to gravity; speeds/accelerations come from CatMotorConfig.
- The visual flips with movement direction.
- Core does not reference UnityEngine.InputSystem; Gameplay does not reference Photon.
- Missing config produces a clear error, not a NullReferenceException.

   Stop and revert.
