# PARALLAX — Design Images

Concept art generated from the prompt list in the original ChatGPT image session (2026-09-10). Filenames are
prefixed with the image number from that prompt list; a `.txt` file next to each image holds the exact prompt
used, with a note on which variant it is when more than one generation exists for the same prompt.

## Continuity suffix

All prompts after the first were meant to be appended with:

> Continuity requirements: Preserve the established Cat A and Cat B designs, body proportions, silhouette
> language and relative scale. Preserve Reality A's established architectural/material vocabulary and Reality
> B's established geometric vocabulary. Do not redesign the protagonists between images. Maintain a consistent
> landscape mobile camera, premium 2.5D rendering approach and production-feasible level design. Treat this as
> another screenshot from the same commercially released game, not a new interpretation of the concept.
